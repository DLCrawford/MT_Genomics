# popgen_selection

Selection statistics for the manuscript: within-species pNs/pS per gene and OXPHOS complex with 95% bootstrap CIs (Table 1, Fig. 2), π/θ by site class for the whole panel and within the Northern and Southern clades (Table 3, Fig. 4), and the multivariant-site sensitivity analysis (Table 4). All scripts import `common.py`; inputs are read from `../vcf/` (`dnds_per_gene.tsv` from `scripts/10_dnds_per_gene.py`, `haplotype_matrix.csv`, `pi_by_clade_persite.tsv`). Run order: 01 → 02 → 03 → 12 → 13 → 04/06. Scripts 08–11 are earlier figure/table variants kept for provenance.
