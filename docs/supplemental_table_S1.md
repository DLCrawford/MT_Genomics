**Supplemental Table S1. Bioinformatic pipeline for mitochondrial
variant analysis in F. heteroclitus.**

Each analysis step is implemented as a numbered, self-contained script.
Heavy compute (read processing, alignment, mt-read extraction, and
variant calling) runs on the HPC cluster (Triton 2, LSF; jobs/);
downstream analyses run locally on macOS (scripts/). The two canonical
files are vcf/Fhet\_MT\_CDS.snps.split.vcf.gz (full coding-region call
set) and vcf/141\_MT\_variants.vcf.gz (the 141-sample, 927-record
analysis set used for all results). Variant calling and all bcftools
steps used htslib/bcftools 1.23.1 built from source.

**Notes**

1\. bcftools version. On the HPC’s linux-ppc64le architecture, bioconda
pins bcftools to 1.6, which silently under-calls variants on these
high-depth mtDNA pileups (6 SNPs vs 289 from bcftools 1.23.1 on
identical BAMs and parameters). All calling therefore used bcftools
1.23.1 built from source, with config.sh injecting it onto the PATH
ahead of the conda environment. See the manuscript Cautionary Note.

2\. Caller provenance (resolved from the VCF header). The 927-variant
set was produced by JOINT calling (jobs/05\_1\_mpileup\_merge.sh): the
canonical VCF header records a single bcftools call -mv --ploidy 1
followed by norm -m -any -f REF (bcftools 1.23.1, 18 May 2026), with no
per-sample output paths and no merge step. The per-sample-then-merge
approach (archived jobs/\_archive/05d2\_persample\_call.sh +
05e2\_merge\_persample.sh) corresponds to a separate, earlier file (15
May 2026) whose header carries a bcftools merge -m none command; that
file was not used for the results. What a pipeline actually executed can
always be read from the ordered \#\#bcftools\_\*Command /
\#\#bcftools\_\*Version lines embedded in each VCF header.

3\. Environments. HPC: conda env mito\_genomics (with bcftools 1.23.1
PATH-injected via config.sh). Mac: conda env SNP\_env (bcftools, pysam,
cyvcf2, pandas, Java).

4\. Cross-species comparison (Table 5). Per-species π/θ for the
comparison datasets are produced by scripts kept alongside each dataset:
Human\_mt/21\_human\_mt\_pi.py and 22\_human\_mt\_cds\_pi.py,
C\_elegans/23\_celegans\_pi.py, and Yeast/24\_yeast\_pi.py, combined by
scripts/25\_comparison\_table.py. (Yeast π is flagged unreliable; see
repository notes.)
